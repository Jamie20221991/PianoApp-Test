# Install Glow Piano

Glow Piano is a progressive web app. Open the published site in a supported browser while online, then use **Install app** or your browser's install option to add it to your device. Once installed, it opens in its own window and the app files are available offline.

On iPhone or iPad, open the site in Safari, tap **Share**, then choose **Add to Home Screen**.

The app's piano sounds are generated in the browser. Internet access may still be needed for optional fonts.
